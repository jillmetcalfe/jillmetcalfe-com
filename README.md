# jillmetcalfe.com

The landing page for Jill Metcalfe's AI staff training workshops. One hand-written HTML page and one stylesheet, served by GitHub Pages. No framework and no build step.

Preview it locally: run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

The blog lives separately at [blog.jillmetcalfe.com](https://blog.jillmetcalfe.com).
